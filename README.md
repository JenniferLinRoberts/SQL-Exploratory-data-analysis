# SQL-Exploratory-data-analysis
Following from my data cleaning project, here I perform some exploratory data analysis. I practised asking questions of a data set with an open-ended goal. I was able logically explore what insights could be gained from the data set and create useful tables to highlight them. 
Through this project I was able to further cement my understanding of SQL and how it can be used for data analysis. By creating a rolling totals table I was able to explore more complex querying. 
Though this is my own work, it follows the tutorials of Alex The Analyst on YouTube.
